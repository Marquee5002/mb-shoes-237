# Scénario de présentation

1. **Accueil** : montrer la nouvelle vitrine et l'accès immédiat aux collections.
2. **Collection** : filtrer les modèles et ouvrir une fiche produit.
3. **Commande existante** : ajouter un modèle à la sélection et montrer le bouton WhatsApp.
4. **Sur mesure** : cliquer « Créer ma paire », importer une photo, choisir les paramètres, afficher le récapitulatif.
5. **WhatsApp** : expliquer que le prototype prépare la demande ; dans la vraie version, le back-office calculera prix, disponibilités et délais.
6. **Atelier** : expliquer que les réalisations peuvent être publiées comme portfolio.
7. **Rendez-vous** : montrer comment les clients éloignés peuvent préparer leur visite.

## Argument commercial
La valeur n'est pas seulement « avoir un site ». Le concept transforme les contenus Instagram/WhatsApp et le savoir-faire de l'atelier en un parcours permanent : découvrir → choisir ou personnaliser → préparer la commande → échanger avec l'atelier → rendez-vous / livraison.
